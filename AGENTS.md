# Инструкции для агентов

## Назначение репозитория

Этот репозиторий содержит публичные шаблоны документации для проектов и пакетов, разрабатываемых через платформу.

## Правила работы

- Ответы пользователю и оформление PR писать на русском языке.
- Тексты commit message писать на английском языке.
- Прямой push в `main` запрещён: изменения вносятся через отдельную ветку и PR.
- Документы писать по-русски, если точность не требует технического идентификатора на английском.
- Шаблон должен оставаться универсальным и не должен фиксировать продуктовый план конкретного проекта.
- Не привязывать шаблон к конкретному проекту-потребителю, slug репозитория или частной delivery-политике.
- Если меняется шаблон, проверить, нужно ли синхронизировать локальную копию в `github.com/codex-k8s/kodex` (`docs/templates/**`).
- Если шаблон ссылается на инженерные правила, использовать публичные репозитории `kodex-guidelines-*`, а не приватные источники.
